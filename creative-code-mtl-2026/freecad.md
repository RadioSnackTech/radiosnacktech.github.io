An introduction to the open-source CAD modelling software FreeCAD, covering the
basic workbenches for designing parametric, high–precision 3D models for digital
fabrication. From defining object parameters, to building precise planar sketches
which then become 3D objects, to understanding modular assembly workflows, this
workshop will give you the basic foundations for designing your own 3D printed
part.
